# JimyBot

بوت لويكيبيديا العربية مكتوب بلغة Python باستخدام مكتبة pywikibot.

## المهام

### 1. إزالة قالب ممر تصفح
إزالة قالب:ممر تصفح وكل تحويلاته من صفحات النطاق الرئيسي.

### 2. التحقق من ملفات SVG
التحقق من صحة ملفات SVG باستخدام W3C Nu Validator وإضافة قالب SVG سليم أو SVG غير سليم.

## المتطلبات

- Python 3.9 أو أحدث
- pywikibot

## التثبيت

pip install pywikibot
